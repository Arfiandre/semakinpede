Deployment Guide: Semakin Pede

Panduan langkah demi langkah implementasi stack Laravel + Inertia (React) pada Ubuntu VPS lengkap dengan Solusi Port Conflict (Multi-Project).

OS: Ubuntu 22.04 / 24.04 LTS
Runtime: PHP 8.3 FPM + Composer
Web Server: Nginx (Port 80/443 atau Custom Port 8080/8081)
Database: MySQL / MariaDB
⚡

Panduan Khusus: Solusi Menabrak Port Project Lain

Multi-Site / Co-Existence

Jika VPS Anda sudah menjalankan project lain (misal Apache, Docker container, atau aplikasi Node.js/Python yang memakai Port 80/443), Anda memiliki 2 pilihan solusi:

Opsi A: Gunakan Custom Port (contoh: Port 8080) Ubah Nginx agar mendengar di listen 8080;, buka firewall UFW (sudo ufw allow 8080/tcp), dan sesuaikan APP_URL.
Opsi B: Nginx Virtual Host (Satu Port, Beda Domain) Jika project lain juga berjalan di Nginx, Anda tidak perlu beda port. Cukup bedakan server_name (misal domain-a.com & domain-b.com).

Langkah 0: Diagnosa Port Yang Sedang Bertabrakan

Jalankan perintah ini di terminal server untuk melihat service apa yang sedang memakai port 80, 443, atau port lainnya: 

# 1. Cek port yang sedang aktif digunakan di server
sudo ss -tulpn | grep -E ':(80|443|8080|8081|3306|5000|3000)'

# 2. Atau cek secara spesifik proses yang menguasai Port 80
sudo lsof -i :80

# 3. Cek apakah ada Apache yang tidak sengaja berjalan
sudo systemctl status apache2

💡 Jika yang muncul adalah apache2 dan Anda hanya ingin memakai Nginx, matikan Apache dengan: sudo systemctl stop apache2 && sudo systemctl disable apache2.

Upgrade PHP ke Versi 8.3 di Ubuntu

Wajib (Mengatasi Isu PHP 8.2)

Laravel membutuhkan PHP 8.3. Tambahkan PPA resmi Ondřej Surý dan pasang ekstensi yang dibutuhkan. 

# 1. Update paket dan tambahkan repository PHP
sudo apt update
sudo apt install -y software-properties-common ca-certificates apt-transport-https
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update

# 2. Pasang PHP 8.3 & Ekstensi Laravel
sudo apt install -y php8.3 php8.3-cli php8.3-fpm php8.3-mysql php8.3-mbstring \
php8.3-xml php8.3-bcmath php8.3-curl php8.3-zip php8.3-intl php8.3-gd php8.3-sqlite3

# 3. Jadikan PHP 8.3 sebagai default CLI & verifikasi
sudo update-alternatives --set php /usr/bin/php8.3
php -v

Setup Database MySQL / MariaDB

Buat database baru beserta pengguna khusus dengan hak akses terbatas untuk aplikasi ini. 

# Masuk ke MySQL prompt
sudo mysql -u root -p

# Jalankan query berikut (ganti GANTI_PASSWORD_KUAT):
CREATE DATABASE semakinpede CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'semakinpede_user'@'127.0.0.1' IDENTIFIED BY 'GANTI_PASSWORD_KUAT';
GRANT ALL PRIVILEGES ON semakinpede.* TO 'semakinpede_user'@'127.0.0.1';
FLUSH PRIVILEGES;
EXIT;
3

Ambil Source Code & Konfigurasi .env

Clone repository dari GitHub, pasang paket PHP via Composer, dan atur kredensial production serta port URL. 

# Buat folder dan beri hak milik ke user Anda
sudo mkdir -p /var/www/semakinpede
sudo chown -R "$USER":"$USER" /var/www/semakinpede

# Clone repository
git clone https://github.com/Arfiandre/semakinpede.git /var/www/semakinpede
cd /var/www/semakinpede

# Install vendor Composer untuk production
composer install --no-dev --prefer-dist --optimize-autoloader --no-interaction

# Konfigurasi file environment
cp .env.example .env
nano .env
Penyesuaian variabel kunci pada .env (Perhatikan APP_URL jika memakai Custom Port):
APP_ENV=production
APP_DEBUG=false
# Jika pakai Port Standar 80/443: APP_URL=https://domainanda.com
# Jika pakai Custom Port 8080: APP_URL=http://domainanda.com:8080 (atau http://IP_VPS:8080)
DB_CONNECTION=mysql
DB_DATABASE=semakinpede
DB_USERNAME=semakinpede_user
DB_PASSWORD=GANTI_PASSWORD_KUAT

5

Atur Hak Akses / Permission Folder (Khusus Ubuntu)

Crucial for Ubuntu

Di Ubuntu, web server berjalan dengan user group www-data. Beri hak tulis pada folder storage dan bootstrap cache. 

# Set kepemilikan file ke user Anda dan group www-data
sudo chown -R $USER:www-data /var/www/semakinpede

# Beri hak baca dan tulis pada storage dan cache
sudo chmod -R 775 /var/www/semakinpede/storage /var/www/semakinpede/bootstrap/cache
6

Konfigurasi Virtual Host Nginx & Penanganan Port

Pilih Konfigurasi Sesuai Port

Pilih opsi konfigurasi di bawah tergantung apakah Anda ingin menggunakan Custom Port (8080) agar tidak menabrak port lain, atau Port Standar (80/443):

Gunakan opsi ini jika: Port 80 di VPS Anda sudah dipakai oleh Apache, Docker, atau aplikasi lain. Nginx akan mendengarkan di Port 8080 (atau ganti ke 8081). 
# Simpan di: sudo nano /etc/nginx/sites-available/semakinpede

server {
    # Nginx mendengarkan di Port Kustom 8081 (atau 8080)
    listen 8081;
    # listen [::]:8081; # Hapus/nonaktifkan jika muncul error 97 (IPv6 disabled di VPS)
    
    server_name domainanda.com www.domainanda.com _;

    root /var/www/semakinpede/public;
    index index.php index.html;
    charset utf-8;

    client_max_body_size 64M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_index index.php;
        fastcgi_buffers 16 16k;
        fastcgi_buffer_size 32k;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
Wajib: Buka Port 8080 di Firewall Ubuntu (UFW) 
# Buka akses port 8080 di firewall
sudo ufw allow 8080/tcp
sudo ufw reload
Gunakan opsi ini jika: Semua project Anda berjalan di dalam Nginx yang sama. Cukup bedakan server_name domain masing-masing. 
# Simpan di: sudo nano /etc/nginx/sites-available/semakinpede

server {
    listen 80;
    # listen [::]:80; # Nonaktifkan jika IPv6 tidak aktif di VPS (mencegah error 97)
    
    # Bedakan nama domain dengan project lain agar tidak bentrok
    server_name semakinpede.com www.semakinpede.com;

    root /var/www/semakinpede/public;
    index index.php index.html;
    charset utf-8;

    client_max_body_size 64M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_index index.php;
        fastcgi_buffers 16 16k;
        fastcgi_buffer_size 32k;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Aktifkan konfigurasi di Ubuntu dan reload Nginx:

# Buat symlink dari sites-available ke sites-enabled
sudo ln -s /etc/nginx/sites-available/semakinpede /etc/nginx/sites-enabled/

# Tes syntax & terapkan konfigurasi
sudo nginx -t && sudo systemctl reload nginx

⚠️ Troubleshooting Port & Error Umum

bind() to 0.0.0.0:80 failed (98: Address already in use): Port 80 sudah dipakai Apache/service lain. Ganti listen port Nginx ke 8080 atau matikan service yang bertabrakan.
Website tidak bisa dibuka di port 8080: Pastikan port 8080 sudah dibuka di firewall: sudo ufw allow 8080/tcp dan security group cloud (jika pakai AWS/DigitalOcean/GCP).
502 Bad Gateway: Socket PHP-FPM tidak cocok atau belum aktif. Cek status: sudo systemctl status php8.3-fpm.
socket() [::]:XXXX failed (97: Unknown error): VPS Anda tidak mengaktifkan modul IPv6 di kernel Linux. Solusi: Hapus atau beri tanda komentar (#) pada baris listen [::]:...; di konfigurasi Nginx.
tempnam(): file created in the system's temporary directory: Laravel gagal menulis cache ke bootstrap/cache atau storage/ karena masalah hak akses (permission). Solusi: Jalankan sudo chmod -R 775 storage bootstrap/cache && sudo chown -R $USER:www-data storage bootstrap/cache.
Cek Log Error Realtime:
sudo tail -f /var/log/nginx/error.log
